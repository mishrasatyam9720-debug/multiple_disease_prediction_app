  # Multiple Disease Prediction App

A Machine Learning-based **Multiple Disease Prediction System** built using **Streamlit**.  
The application predicts the possibility of **Diabetes, Heart Disease, and Parkinson's Disease** using trained machine learning models.

## Features
- Diabetes Prediction
- Heart Disease Prediction
- Parkinson's Disease Prediction
- User-friendly Streamlit interface
- Pre-trained ML models and scaler included

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## Project Files
- `multiple_disease_prediction.py` – Main Streamlit application
- `.sav` files – Trained ML models
- `scaler_model (1).sav` – Feature scaler
- `requirements.txt` – Required Python libraries

## Run Locally

```bash
pip install -r requirements.txt
streamlit run multiple_disease_prediction.py
